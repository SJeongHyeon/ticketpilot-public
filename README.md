# TicketPilot

TicketPilot은 Windows에서 예매 시작 시각을 한국 표준시(KST) 기준으로 관리하고 알려 주는 개인용 데스크톱 도우미입니다. 공연명, NOL Ticket 상세 페이지 URL, 예매 시작 일시를 저장하면 카운트다운과 사전 알림을 제공합니다.

> [!IMPORTANT]
> 실제 NOL 사이트에서는 사용자가 직접 예매 버튼을 클릭해야 합니다. TicketPilot은 실제 NOL 페이지를 자동으로 클릭하거나 조작하지 않습니다. 자동 클릭은 `127.0.0.1`에서 제공하는 **로컬 테스트 페이지에서만** 동작합니다.

## 주요 기능

- 공연명, NOL Ticket 공연·스포츠 상세 URL, 예매 시작 일시(KST) 저장
- 시·분·초 카운트다운 및 시작 10분 전·1분 전·정각 알림
- 설정을 `config.json`에 저장하고 다음 실행 시 불러오기
- 실제 NOL 페이지 또는 로컬 테스트 페이지를 기본 브라우저로 미리 열기
- NOL 알림 모드에서 정각 알림 및 직접 클릭 안내
- 로컬 테스트 모드에서 테스트 페이지의 버튼을 정각에 한 번만 자동 클릭
- 로컬 테스트의 예정·실제 클릭 시각과 차이를 밀리초 단위로 실행 로그에 기록
- 중지 시 카운트다운과 로컬 테스트 예약을 함께 취소
- 로컬 테스트 페이지가 닫혔거나 열려 있지 않으면 예약을 취소
- `nol.yanolja.com`, `ticket.nol.com` 및 하위 도메인의 HTTP(S) 상세 URL 검증

## 요구사항

- Windows 10/11
- Python 3.10 이상 (Tcl/Tk 포함 배포판)
- pip

런타임 라이브러리는 [requirements.txt](requirements.txt)에 정의되어 있습니다.

| 패키지 | 용도 |
| --- | --- |
| `customtkinter` | 데스크톱 GUI |
| `tzdata` | KST 시간대 데이터 |

테스트에는 표준 라이브러리 `unittest`를 사용하며, 로고 이미지 검증을 위해 Pillow가 필요합니다. `customtkinter` 설치 환경에 Pillow가 없다면 테스트 전 `python -m pip install Pillow`를 추가로 실행하세요.

## 설치 방법

PowerShell에서 프로젝트 폴더로 이동한 뒤 가상 환경을 만들고 의존성을 설치합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

PowerShell 실행 정책으로 가상 환경 활성화가 차단되면, 해당 환경의 실행 정책을 확인하거나 가상 환경의 Python 경로를 직접 사용하세요.

## 실행 방법

```powershell
python main.py
```

1. 공연명과 NOL Ticket의 실제 공연 또는 스포츠 **상세 URL**을 입력합니다.
2. **예매 시작 날짜** 버튼을 눌러 달력에서 연·월·일을 선택합니다. 달력의 `‹`, `›` 버튼으로 이전·다음 달로 이동할 수 있으며, 처음에는 현재 KST 날짜가 선택됩니다.
3. **예매 시작 시각**의 시·분·초 선택기에서 24시간제 시각을 선택합니다. 각각 `00~23`, `00~59`, `00~59` 범위를 제공합니다.
4. 실행 방식을 선택합니다.
5. **페이지 미리 열기**로 해당 페이지를 열고, **시작**을 누릅니다. 시작 시각은 현재 KST보다 미래여야 합니다.

## NOL 알림 모드와 로컬 테스트 모드

| 구분 | NOL 알림(직접 클릭) | 로컬 테스트 자동 클릭 |
| --- | --- | --- |
| 대상 페이지 | 사용자가 입력한 실제 NOL Ticket 상세 페이지 | 앱이 제공하는 `http://127.0.0.1:<port>/local-test` |
| 정각 동작 | 알림음·안내를 표시하고 사용자의 클릭을 기다림 | 로컬 페이지의 **예매하기** 버튼을 한 번 자동 클릭 |
| 외부 사이트 자동 조작 | 하지 않음 | 하지 않음 |
| 용도 | 실제 예매 시작 시각 알림 | 클릭 예약과 시간 기록의 로컬 검증 |

### 실제 NOL 이용 순서

1. **NOL 알림(직접 클릭)**을 선택합니다.
2. **페이지 미리 열기**로 실제 상세 페이지를 열어 둡니다.
3. **시작**을 누른 뒤, 정각 알림이 오면 브라우저에서 사용자가 직접 예매를 진행합니다.

### 로컬 테스트 순서

1. **로컬 테스트 자동 클릭**을 선택합니다.
2. **페이지 미리 열기**를 눌러 로컬 테스트 페이지를 엽니다.
3. **시작**을 누르고 테스트 페이지를 정각까지 열어 둡니다.
4. 앱 로그에서 예정 시각, 실제 클릭 시각, 밀리초 차이를 확인합니다.

## 프로그램 실행 화면

실행하면 상단에 카운트다운, 가운데에 예매 정보와 실행 방식 선택, 하단에 제어 버튼과 실행 로그가 표시됩니다.

```text
TicketPilot | 개인 예매 시작 알림

                예매 시작까지
                  00:10:00

공연명             [ 2026 콘서트                         ]
NOL Ticket URL     [ https://ticket.nol.com/...           ]
예매 시작 날짜     [ 2026-10-26 ▼ ]  예매 시작 시각 [ 12 ▼ ] [ 30 ▼ ] [ 00 ▼ ]
실행 방식          (•) NOL 알림(직접 클릭)  ( ) 로컬 테스트 자동 클릭

[설정 저장]  [시작]  [중지]  [페이지 미리 열기]

실행 로그
[12:00:00] 감시 시작: 2026-10-26 12:10:00 KST
```

## 테스트 실행 방법

가상 환경을 활성화한 상태에서 다음을 실행합니다.

```powershell
python -m pip install Pillow
python -m unittest discover -s tests -v
python -m py_compile main.py app.py browser_launcher.py config_manager.py local_test_server.py scheduler.py validators.py
```

테스트는 URL 검증, 설정 저장, 알림 시점, 중지 처리, 로컬 예약의 중복 방지와 로컬 테스트 서버 동작을 확인합니다. 실제 브라우저를 열거나 외부 NOL 사이트로 요청하지 않습니다.

## Windows EXE 빌드 및 실행

빌드는 문제 확인이 쉬운 `onedir` 방식입니다. 즉, `TicketPilot.exe`와 실행에 필요한 라이브러리·이미지가 함께 들어 있는 `dist\TicketPilot` 폴더 전체를 유지해야 합니다.

### 빌드하기

1. PowerShell에서 프로젝트 폴더를 엽니다.
2. Python 3.10 이상(반드시 Tcl/Tk 포함)을 설치했는지 확인합니다.
3. 처음 한 번만 빌드 도구를 설치합니다.

```powershell
python -m pip install pyinstaller
```

4. 아래 명령을 실행합니다.

```powershell
.\build_exe.ps1
```

완료되면 실행 파일은 `dist\TicketPilot\TicketPilot.exe`에 생성됩니다. EXE 아이콘에는 `assets\app.ico`가 사용되며, `assets\logo.png`와 `assets\app.ico`도 배포 폴더에 포함됩니다. CustomTkinter·Pillow·Tcl/Tk 관련 런타임 파일 역시 PyInstaller가 함께 복사합니다.

### EXE 수동 확인 방법

1. 파일 탐색기에서 `dist\TicketPilot`을 엽니다.
2. `TicketPilot.exe`를 더블클릭합니다. 처음 실행할 때 Windows Defender SmartScreen 경고가 보이면, 출처와 파일을 신뢰하는 경우에만 **추가 정보 → 실행**을 선택합니다.
3. 창 상단에 파란 로고와 `TicketPilot` 제목이 보이는지 확인합니다.
4. 테스트용 공연명과 허용되는 NOL Ticket 상세 URL 형식을 입력합니다. 날짜 버튼을 눌러 미래 날짜를 선택하고, 시·분·초 선택기에서 미래 KST 시각을 고른 뒤 **설정 저장**을 누릅니다. 실제 NOL 사이트를 열거나 **페이지 미리 열기**를 누를 필요는 없습니다.
5. 프로그램을 닫고 `TicketPilot.exe`를 다시 더블클릭합니다. 입력한 설정이 다시 표시되면 저장 확인이 완료된 것입니다.
6. 파일 탐색기의 주소 표시줄에 `%LOCALAPPDATA%\TicketPilot`을 입력합니다. 그 안의 `config.json`이 수정된 것을 확인합니다. `dist\TicketPilot` 안에는 `config.json`이 생기지 않아야 합니다.
7. `dist\TicketPilot` 폴더를 통째로 다른 위치에 복사한 뒤에도 EXE가 실행되는지 확인합니다. EXE만 따로 옮기면 필요한 `_internal` 파일이 없어 실행되지 않습니다.

실제 NOL 예매 검증은 하지 마세요. 실제 페이지의 클릭과 예매는 항상 사용자가 직접 수행해야 하며, 자동 클릭 검증은 앱의 `로컬 테스트 자동 클릭` 모드와 `127.0.0.1` 테스트 페이지에서만 하세요.

## 사용 시 주의사항

- 이 도구는 개인적인 예매 시각 확인과 로컬 검증을 위한 보조 프로그램입니다.
- 실제 NOL 페이지에는 자동 로그인, 대기열 조작, 자동 새로고침, 좌석 자동 선택, 자동 클릭, 자동 결제 기능이 없습니다.
- 실제 NOL 사이트에서의 모든 클릭과 예매 진행은 사용자의 책임으로 직접 수행해야 합니다.
- 자동 클릭 기능은 반드시 `127.0.0.1` 로컬 테스트 페이지에서만 사용됩니다. 실제 NOL URL에는 적용되지 않습니다.
- URL에는 공연 또는 스포츠의 상세 페이지 주소를 입력하세요. 허용되지 않은 도메인, 포트·사용자 정보·fragment(`#...`)가 포함된 URL, 상세 경로가 없는 URL은 거부됩니다.
- `config.json`에는 입력한 공연명·URL·일시가 저장됩니다. 이 파일은 `.gitignore`에 포함되어 있으므로 저장소에 올리지 마세요.
- 네트워크 상태, 브라우저·운영체제 스케줄링 및 실제 서비스 상황에 따라 알림이나 로컬 테스트 기록 시점에는 오차가 있을 수 있습니다. 실제 예매 성공을 보장하지 않습니다.
